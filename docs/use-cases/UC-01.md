## Descripción

Primer proyecto a crear por ser el más simple (sin base de datos ni dependencias). Crear la solución `NiuroTest.slnx` y el proyecto `Niuro.Mock` (Minimal API .NET) en `mock/`. Simula el servicio externo de terceros: recibe el payload (customer + application), responde `200` y conserva lo recibido en memoria para inspección/demo (UC-15).

Junto con la solución se crea **`Directory.Packages.props`** (Central Package Management): el archivo que centraliza las versiones de los paquetes NuGet de toda la solución. Cada caso de uso lo **actualiza** conforme instale algún paquete (agrega su `<PackageVersion>`).

> El mock es un **servicio de terceros**: no se instrumenta con nuestro logging (Serilog). No loguea al archivo compartido `logs/niuro-backend-*.log`.

**Estándar de nombres**: cada proyecto se llama `Niuro.{Proyecto}` (p. ej. `Niuro.Mock`) para mantener consistencia en todo el repo.

## Precondiciones

- SDK .NET 10 instalado.

## Flujo principal

1. Ejecutar `dotnet new sln -n NiuroTest` en la raíz.
2. Crear **`Directory.Packages.props`** en la raíz con `<ManagePackageVersionsCentrally>true</ManagePackageVersionsCentrally>` y los `<ItemGroup>` de `<PackageVersion>`. Los UCs posteriores agregan aquí las versiones de los paquetes que vayan instalando (Serilog en UC-02/03, EF Core/Npgsql en UC-06, etc.).
3. Ejecutar el template de Minimal API (`dotnet new web` o `dotnet new webapi` según versión) con nombre `Niuro.Mock` en `mock/`.
4. Agregar a la solución: `dotnet sln add mock/Niuro.Mock.csproj`.
5. Verificar compilación: `dotnet build`.

## Excepciones

- El mock es intencionalmente simple: sin base de datos, sin auth, sin reintentos entre endpoints, y **sin nuestro logging** (es el servicio externo). Cualquier extra debe justificarse en el ARCHITECTURE.md.
- Con CPM activado, los proyectos **no** deben declarar versiones de paquetes directamente: solo referencian el paquete y la versión central vive en `Directory.Packages.props`.

## Postcondiciones

- La solución `NiuroTest.slnx` existe con `mock/` (proyecto `Niuro.Mock`) agregado y compilando, y con **CPM habilitado** (`Directory.Packages.props`).
- `mock/` es independiente (no comparte código con `backend/`/`worker/`).
