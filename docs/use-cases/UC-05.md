# UC-05 · Crear la app Next.js `frontend/`

| Campo | Valor |
|---|---|
| **Fase** | 0 — Preparación del entorno |
| **Tipo** | Desarrollo |
| **Actor** | Equipo de desarrollo |

## Descripción

Generar `frontend/` con Next.js (App Router, TypeScript, renderizado en **cliente**: sin Server Components ni Server Actions). Usa **PrimeReact** como librería de controles (inputs, botones, mensajes ya hechos) con **estilos Bootstrap** (se importa el theme de PrimeReact y se complementa con la estética Bootstrap para que los controles se vean consistentes). Se comunica con `backend/` por HTTP usando `NEXT_PUBLIC_API_URL`, disponible en todo el árbol vía **React Context** (slice de config, sin librería de estado externa).

**Estándar de nombres**: el paquete npm se llama `niuro-frontend` (la carpeta es `frontend/`), siguiendo el mismo estándar `niuro-*` aplicado a los proyectos .NET.

## Precondiciones

- Node.js instalado.

## Flujo principal

1. Ejecutar `npx create-next-app@latest frontend --ts --app --no-tailwind` (o flags equivalentes de la versión actual) en la raíz. Si `create-next-app` pregunta por el nombre del paquete, usar `niuro-frontend`.
2. Instalar PrimeReact y sus iconos: `npm install primereact primeicons`.
3. Configurar los estilos: importar el theme de PrimeReact (`primereact/resources/themes/.../theme.css`), `primereact/resources/primereact.min.css`, `primeicons/primeicons.css` y la hoja de estilos Bootstrap en el layout (para que los client components los consuman).
4. **Crear el `.env.local` de una vez** con `NEXT_PUBLIC_API_URL=http://localhost:<puerto-api>` y el `.env.example` como plantilla versionable.
5. Crear el **slice de config con React Context** (`lib/config/ConfigProvider.tsx` + hook `useConfig()`): expone `apiUrl` leída de `process.env.NEXT_PUBLIC_API_URL`; el `ConfigProvider` se monta en el layout para que el formulario (UC-07) y las páginas de resultado lo consuman.
6. Verificar arranque: `npm run dev`.

## Excepciones

- **Bootstrap como framework de CSS completo queda descartado** — PrimeReact es la librería de controles; los estilos Bootstrap se usan solo como base visual del theme de los controles.
- Las variables `NEXT_PUBLIC_*` se resuelven en build-time → cambiar el puerto del API requiere reiniciar `npm run dev`.
- Versión de Next.js instalada puede variar; documentar en el README los comandos exactos usados.

## Postcondiciones

- App Next.js compila y arranca en modo dev, con PrimeReact + estilos Bootstrap.
- `.env.local` y `.env.example` creados; la config (API URL) disponible vía `useConfig()` (React Context) en todo el árbol.
- Lista para implementar el formulario del UC-07 (lado cliente).
