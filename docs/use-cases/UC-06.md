# UC-06 · Inicializar la base de datos (code-first)

| Campo | Valor |
|---|---|
| **Fase** | 0 — Preparación del entorno |
| **Tipo** | Desarrollo |
| **Actor** | Equipo de desarrollo |

## Descripción

Definir el `DbContext` (con las entidades `Customer`, `Application`, `OutboxEvent` y blacklist), generar las **migraciones** del esquema y la de **seed** (datos fake: SSNs en blacklist) usando EF Core code-first. Las migraciones se generan **sin** PostgreSQL corriendo (`dotnet ef migrations add` no conecta); se aplican al levantar la BD con Docker (`dotnet ef database update` o al arrancar el API).

## Precondiciones

- `UC-02` completado (existe `core/` con `Niuro.Core`). `dotnet-ef` instalado (`dotnet tool install --global dotnet-ef`).
- Paquetes EF Core + Npgsql en `core/`.

## Flujo principal

1. Crear `DbContext` y entidades en `core/` (infraestructura).
2. Ejecutar `dotnet ef migrations add InitialCreate` (proyecto `core/`).
3. Ejecutar `dotnet ef migrations add SeedBlacklist` con los datos fake de prueba.
4. Documentar en el README cómo aplicar (`dotnet ef database update` con PostgreSQL en Docker).

## Excepciones

- El provider **in-memory de EF Core NO está permitido** (no soporta transacciones reales). Usar Npgsql/PostgreSQL.

## Postcondiciones

- Migraciones versionadas en `core/`.
- Al aplicar sobre PostgreSQL quedan las tablas correctas y la blacklist seedeada (SSNs de prueba).
