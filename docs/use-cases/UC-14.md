# UC-14 · Recibir y confirmar los datos el Servicio Externo

| Campo | Valor |
|---|---|
| **Fase** | 4 — Evento en background al servicio externo |
| **Tipo** | Negocio |
| **Actor** | Servicio Externo (Mock) |

## Actores y proyectos involucrados

- `mock/` (`Niuro.Mock`): Minimal API .NET, **intencionalmente simple** (sin DB, sin auth, sin logging a nuestro archivo).
- `worker/` (`Niuro.Worker`): emisor del payload (UC-13).
- `frontend/`/equipo: puede consultar lo recibido (UC-15).

## Descripción

El mock recibe el payload (customer + application) del worker por HTTP y responde `200`. Guarda lo recibido **en memoria** (diccionario clave SSN) para inspección/demo (UC-15).

## Contrato técnico (mock)

```
POST http://localhost:5200/api/customers              → 200 Created (create)
PUT  http://localhost:5200/api/customers/{ssn}        → 200 OK      (update)
GET  http://localhost:5200/api/customers              → 200 lista   (UC-15, solo lectura)
```

**Payload** del POST/PUT (aplica lo definido en UC-13): `{ customer: {...}, application: {...} }`.

**Respuestas:**
- `200` OK (o `201 Created` para el POST a discreción) tras guardar en memoria.
- `400`/`422` con Problem Details si el payload no cumple el contrato mínimo (campos requeridos presentes, `requestedAmount > 0`, formato de SSN).
- Negocio: el mock **no** guarda ni valida contra reglas del banco (es un tercero fake).

**Clave natural**: el mock usa el **SSN** como clave del diccionario en memoria. `POST` agrega la entrada; `PUT /customers/{ssn}` la **actualiza** (misma llave → no duplica).

## Flujo principal

1. El worker envía `POST /api/customers` (create) o `PUT /api/customers/{ssn}` (update) con el payload (UC-13).
2. El mock valida el payload de forma mínima.
3. Almacena en memoria (upsert por SSN) y responde `200`.

## Excepciones

- Payload fuera del contrato → `400`/`422`; el worker marca el evento como `Failed` (UC-13).
- Mock caído → el worker no obtiene respuesta; evento `Failed` con el error (UC-13).

## Postcondiciones

- El mock confirma la recepción con `200`.
- Lo recibido queda disponible en memoria para consulta (UC-15).
