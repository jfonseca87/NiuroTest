# UC-04 · Crear el proyecto de tests

| Campo | Valor |
|---|---|
| **Fase** | 0 — Preparación del entorno |
| **Tipo** | Desarrollo |
| **Actor** | Equipo de desarrollo |

## Descripción

Crear el proyecto xUnit para los tests del backend (unitarios del rule engine + integración del endpoint/transacción con `WebApplicationFactory` y Testcontainers PostgreSQL).

## Precondiciones

- `UC-02`, `UC-03` completados.

## Flujo principal

1. Ejecutar `dotnet new xunit -n Niuro.Tests -o tests`.
2. Agregar referencias: test project → `Niuro.Api` (`backend/`) y `Niuro.Core` (`core/`).
3. Agregar paquetes: `Microsoft.AspNetCore.Mvc.Testing` y `Testcontainers.PostgreSql`.
4. Agregar a la solución y verificar `dotnet build`.

## Excepciones

- Docker debe estar corriendo para los tests de integración que usan Testcontainers (los unitarios del rule engine no lo requieren).

## Postcondiciones

- Proyecto de tests compila.
- Cobertura enfocada: rule engine, customer que regresa y endpoint (no 100%).
